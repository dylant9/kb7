# Security policy

This repository does not currently publish flashable firmware. Treat any claim
that an artifact is safe to install as a security issue.

Please report privately before public disclosure if you find:

- a path that generates or packages a flash image;
- vendor firmware, a device dump, raw capture, or decompiler output in the
  repository or its history;
- a hardware path that is enabled despite being documented as fail-closed;
- an unsafe erase/program range, recovery regression, or persistent key state;
- a parser memory-safety issue.

No dedicated security contact is currently documented. Repository owners should
enable GitHub confidential vulnerability reporting or publish a non-public
contact as soon as practical; until then, avoid posting exploit details in a
public issue.
